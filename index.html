About your data

Everything lives in this browser only (localStorage). No server, no account.

  • Persists across reloads and browser restarts.
  • Tied to this device + browser. Phone and laptop are separate stores.
  • Clearing browser data deletes it. Incognito mode doesn't persist.
  • To move between devices: export JSON → transfer file → import on the other device.
